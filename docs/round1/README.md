# Round 1: the submission documents

What Team SE7EN submitted for Round 1 of the Samsung PRISM GenAI Hackathon 3.0 (Theme 05), on 30 Sep 2026. The
submission itself is frozen at tag **`PRISM_GENAI_HACKATHON_Y2026`** (commit `22ca240`), which also holds the
extension's Round 1 demo clips (`results/galaxy/video/`) and DUET v1 on the original Theme 05 kit (`legacy/`).
These copies are kept here as the record. The project has moved on since then, so the current state is in the
[README](../../README.md) and [docs/round2](../round2/README.md).
